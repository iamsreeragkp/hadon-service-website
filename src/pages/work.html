01 / 03

Client profile
US-based B2B financial software startup
Project type
Web application redesign & fullstack optimization
Engagement
1 Senior Fullstack Developer + 1 Senior Product Designer (6 weeks)
Tech stack
Next.js (App Router), TypeScript, Tailwind CSS, PostgreSQL, Prisma, Chart.js

The problem

The client had built an early MVP that suffered from significant performance bottlenecks. Complex financial queries took 4.5 seconds to render, data visualizations broke on mobile screens, and new enterprise users abandoned the onboarding process due to confusing navigation.

The Hadon solution

  • Product designer

    Restructured 28+ screens into a cohesive 12-column layout in Figma. Built high-density financial tables with custom filtering, column reordering, and instant CSV export.

  • Senior developer

    Migrated the frontend to Next.js App Router with React Server Components. Implemented server-side caching and optimized PostgreSQL queries using database indexes and connection pooling.

720msPage load time, down from 4.5s
+48%Increase in daily active user retention
3.5xImprovement in complex query response times

02 / 03

Client profile
Southeast Asian regional logistics & mobility startup
Project type
Real-time dispatch engine & operations control center
Engagement
Dedicated Product Pod (8 weeks)
Tech stack
Node.js, TypeScript, React, WebSockets, Redis, PostgreSQL, Figma

The problem

A fast-growing delivery platform in Singapore and Malaysia was struggling with real-time driver dispatch. Dispatchers experienced multi-second latency spikes during peak hours, causing misallocated orders and customer complaints.

The Hadon solution

  • Product designer

    Designed an operational “air-traffic control” UI in Figma featuring real-time map clustering, urgent order alerts, and 1-click manual driver reassignment.

  • Senior developer

    Built an event-driven Node.js backend utilizing Redis pub/sub and WebSockets to push live location updates to thousands of connected clients simultaneously.

<100msLatency for real-time dispatch updates
25,000+Daily booking transactions handled without performance degradation
99.98%System uptime across peak holiday delivery windows
