AI-powered bookkeeping & financial management platform.

01 / 03

Client profile
FinTech product for small businesses & independent entrepreneurs
Project type
AI bookkeeping platform: web & mobile applications
Platforms
Web application + cross-platform mobile app
Tech stack
React, React Native, Node.js (Express), PostgreSQL, OpenAI API, OCR

The problem

Small business owners still run their books on spreadsheets and paper receipts. Entering every transaction by hand is slow, income and expenses get miscategorised, records end up scattered across tools, and preparing reports for tax time takes far more effort than it should.

The Hadon solution

  • Receipt to ledger, automated

    Users upload income and expense receipts from the web or mobile app. OCR extracts the amount, date, merchant and other fields, and OpenAI models classify each transaction as income or expense and assign a category such as sales revenue, office expenses or transportation.

  • Ledger & reporting

    Classified transactions are written to structured digital ledgers in PostgreSQL. At the end of each reporting cycle the platform consolidates them into financial reports that support bookkeeping and tax preparation.

  • Web & mobile

    React and React Native deliver one consistent experience across platforms, backed by a Node.js and Express API that handles authentication, receipt workflows and the AI processing layer.

AI-powered smart tenant management platform.

02 / 03

Client profile
PropTech product for property owners, facility managers & residential and commercial communities
Project type
Tenant experience & property management platform with an AI support agent
Platforms
Web application + cross-platform mobile app
Tech stack
React, React Native, Node.js (Express), PostgreSQL, OpenAI APIs

The problem

Property teams were juggling disconnected channels. Tenants reached managers through scattered messages, maintenance requests were categorised, prioritised and assigned by hand, shared amenities had no organised booking, and there was no single place to run community events or keep residents engaged.

The Hadon solution

  • AI ticket agent

    Tenants describe an issue in plain language. An OpenAI-powered agent understands the request, categorises it (plumbing, electrical, security, housekeeping and more), assesses priority, structures it into a ticket and helps route it to the right team. Admins can review and approve AI classifications on sensitive or high-priority issues.

  • One tenant app

    Facility reservations, community social feeds and announcements, event creation and registration, and support tickets, all in one web and mobile experience.

  • Admin console

    Property managers get a single view of tenants, bookings, events and tickets, with a Node.js and Express API and PostgreSQL data layer behind it.

Designing a mobile device security & protection platform.

03 / 03

Client profile
Digital safety product for device owners and second-hand mobile retailers
Project type
Product & UX design for an IMEI-based security and theft-reporting platform
Platforms
Android mobile application + web platform
Tech stack
React, React Native, Firebase, Cloud Firestore

The design challenge

Device security is a stressful, high-stakes subject for non-technical people. Theft victims need to report quickly and with confidence, owners need to see their protection status at a glance, and second-hand retailers need an answer they can trust in seconds. Three audiences with different needs had to fit into one product, without asking anyone to understand IMEI numbers or security jargon.

The Hadon design approach

  • Simplicity, clarity, trust

    Three principles guided every screen: no technical knowledge required, essential status always visible, and predictable navigation with clear confirmation steps for sensitive moments.

  • Three journeys

    The owner experience puts registration and protection status first. The theft-report flow breaks a stressful task into guided steps with structured forms and clear next actions. The retailer flow returns an IMEI verification result that reads in seconds.

  • Visual language

    Clean layouts, strong hierarchy, consistent type and spacing, and distinct status treatments for protected, pending and reported-stolen devices, built from reusable components across mobile and web.

  • Error prevention

    Input validation, confirmation steps and meaningful feedback reduce incorrect submissions. Verification results are labelled as based on platform records, never as a guarantee of ownership.
